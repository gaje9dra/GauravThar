# Gaurav Thar — Premium Car Rental

A premium black-and-silver car rental landing page built from scratch.

## Current phase

Phase 1 establishes the visual foundation:
- Luxury black / silver design system
- Responsive navigation
- Cinematic hero section
- Featured vehicle presentation
- Rental search bar
- Fleet collection cards
- Premium service/experience sections
- Mobile responsive layout

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static web server.

## Next

The next phase can add real vehicle data, booking flow, authentication, payments, availability, customer accounts, and an admin dashboard.
